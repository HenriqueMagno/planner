# ✈️ plann.er

Aplicação web para planejamento de viagens, desenvolvida durante o **NLW16 Journey — React**, da Rocketseat.

A aplicação permite criar uma viagem, definir destino e período, convidar participantes e visualizar as informações da viagem de forma organizada.

## Funcionalidades

- Criação de viagens
- Seleção de destino
- Seleção do período da viagem
- Convite de participantes
- Alteração de destino e datas
- Formulário para confirmação da viagem
- Validação dos dados informados
- Navegação entre páginas
- Interface responsiva

## Sobre o projeto

O **plann.er** foi desenvolvido como projeto prático do **NLW16 Journey — React**, com o objetivo de colocar em prática conceitos de desenvolvimento Front-end utilizando React e TypeScript.

A aplicação simula uma plataforma de planejamento de viagens, permitindo que o usuário informe o destino e as datas, convide participantes e acompanhe as informações da viagem.
